# EduPro School ERP — v3.0.0

نظام إدارة مدرسة خاصة دولية متكامل — تطبيق ويب تقدمي (PWA) يعمل **دون إنترنت بالكامل**، بالعربية RTL، بهوية بصرية زجاجية (Glassmorphism) وأيقونات ثلاثية الأبعاد.

## 🚀 التشغيل

### على الحاسوب
```bash
cd edupro-school-erp
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

### على أندرويد
1. ارفع المجلد على أي استضافة (GitHub Pages / Netlify / Vercel) وافتح الرابط من المتصفح ← «إضافة إلى الشاشة الرئيسية» (يعمل كتطبيق PWA دون إنترنت).
2. أو غلّفه بـ Capacitor (WebView) كما في مشروع Alkhobajy-School — الملفات متوافقة مع `setDomStorageEnabled(true)`.

### GitHub Pages
```bash
git init && git add . && git commit -m "EduPro v3.0.0"
git branch -M main && git remote add origin https://github.com/USER/REPO.git
git push -u origin main
# فعّل Pages من إعدادات المستودع ← Branch: main
```

## 🖨️ الطباعة (تحل مشكلة أندرويد)

- **على الجوال/أندرويد**: القناة الأساسية هي **تنزيل PDF** (html2canvas + jsPDF) — موثوقة 100% داخل WebView، بجودة بصرية مطابقة للمعاينة.
- **طباعة حرارية** 80مم/58مم للسندات (إيصال أقساط، تسليم زي/كتب، قسيمة راتب) مع تفقيط المبلغ عربياً + QR.
- **A4 عمودي/أفقي** بثيمات دولية (Royal Blue / Emerald / Gold / Purple) مع ترويسة الشعار والعلامة المائية والتظليل المتناوب — كلها من إعدادات الطباعة وتُطبَّق فعلياً.
- تصدير **Excel** (SheetJS) و **Word**.

## 🔐 الأمان

- تخزين محلي **مشفّر AES-GCM 256** (WebCrypto) بمفتاح رئيسي عشوائي.
- كلمات مرور مجزأة SHA-256 + ملح لكل مستخدم.
- جلسة 30 يوماً بتجديد انزلاقي (لا يسأل الدخول كل مرة).
- 5 أدوار بصلاحيات (مدير/محاسب/شؤون طلاب/مدرس/مشاهد) + سجل حركات كامل.
