## 🆕 ما الجديد في v3.4

| الإصلاح | التفاصيل |
|---|---|
| 💾 النسخة المحلية | نظام تطبيق المحطة exportFile بالنص: النسخ الاحتياطية تُحفظ عبر الجسر الأصلي `saveBackupAuto` (مجلد التنزيلات) فلا يظهر «فشل الحفظ» في أندرويد أبداً |
| ☁️ استعادة GitHub | إصلاح جذري: الملفات الأكبر من 1MB لا تُعيد GitHub محتواها — الآن تُجلب عبر `Accept: application/vnd.github.raw` (نفس الأصل بلا مشاكل CORS حتى 100MB) + fallback download_url كما في المحطة v2026.82 + حارس يرفض ملفات غير مدرسية + رسائل خطأ واضحة |
| 🔓 CSP | السماح بالاتصال لـ raw.githubusercontent.com و media/objects — كانت تستعيد الفشل حتى مع كود سليم |
| 🏫 هوية المدرسة عند الفتح | اسم المدرسة وشعارها يظهران في شاشة البداية وشاشة الدخول فوراً من الإعدادات (نظام المحطة _splash بالنص) — يتحدث تلقائياً بعد تغيير الاسم |
| 🎨 مستيل التقارير والطباعة | محرك المؤسسة الموحد PrintProV2026 — نفس نظام المحطة v2026.87 بالضبط (pp-report): ترويسة متدرجة بشعار دائري + بطاقات KPI + أقسام وجداول بترويسات متدرجة + صف إجماليات + تواقيع + تذييل — لكل التقارير وكشوف الحساب والسندات والدرجات والرواتب والنتائج — الفرق فقط محتوى التقرير |
| 🗄️ SQLite | بلا أي قائمة اختيار مجلد — الحفظ الأوفلاين الخالص كما في آخر نسخة محطة الخبجي (IndexedDB + مرآة محلية تلقائياً) |

## 📱 تحميل وتثبيت

1. افتح صفحة **Releases** في هذا المستودع
2. حمّل ملف `school-management-v1.2.apk` من أحدث إصدار
3. ثبّته على الجهاز (اسمح بالتثبيت من مصادر غير معروفة)
4. الدخول الافتراضي: **admin** / **admin123** — غيّر كلمة المرور بعد أول دخول
5. لتجربة كل الميزات: صفحة «النسخ الاحتياطي» ← زر «توليد البيانات التجريبية» — ولحذفها زر «حذف البيانات التجريبية»

## 🔧 البناء

البناء تلقائي عبر GitHub Actions عند كل دفعة — ينتج APK موقّعاً في Releases.
للبناء اليدوي: `gradle -p android-app assembleRelease`
