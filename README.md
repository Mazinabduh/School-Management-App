## ✨ ما في هذا التطبيق

| المجال | التفاصيل |
|---|---|
| 🖨️ الطباعة | محرك الطباعة الموثوق (iframe معزول — محتوى الطباعة فقط بلا أيقونات البرنامج) + إعدادات كاملة: عدد النسخ، نوع الصفحة A4/A5/Letter/مخصصة، اتجاه ↕ عمودي / ↔ أفقي، هوامش كاملة، نوع وحجم الخط + حجم كل قسم، معاينة مباشرة، طباعة تجريبية |
| 📋 قائمة الطلاب | بنفس شكل قائمة المشتركين: بطاقات قابلة للتوسيع + عرض 50 ثم زر «المزيد» + أزرار: الملف • اتصال • الأقساط • بطاقة • تعديل • حذف |
| 📤 التصدير | Excel (xlsx) + Word (doc) + PDF سريع (html2canvas) + CSV |
| 🔐 الدخول | شاشة دخول native بنمط المحطة: خلفية Canvas متحركة + شعار داخل حلقة دوّارة + إظهار/إخفاء كلمة المرور + «تذكرني» — حفظ مرة واحدة ولا يُطلب الدخول مرة أخرى (مرآة الجلسة في SharedPreferences) |
| 🏢 الهوية | شعار YCMS في شاشة الإقلاع والدخول وأيقونة التطبيق و«حول البرنامج» + جميع الحقوق محفوظة لشركة YCMS |
| 🗑️ البيانات | التطبيق يبدأ **فاضياً تماماً** — تستعيد بياناتك القديمة من النسخة الاحتياطية (JSON/Excel) |
| 🎓 الوحدات | الطلاب، المراحل والصفوف، رصد الدرجات، النتائج والشهادات، الأقساط والفواتير، الميزانية، الزي والكتب، الباصات، الموظفين والرواتب، استوديو البطاقات، التواصل مع أولياء الأمور، مركز التقارير، سجل الحركات، النسخ الاحتياطي |

## 📱 تحميل وتثبيت

1. افتح صفحة **Releases** في هذا المستودع
2. حمّل ملف `school-management-v1.0.apk` من أحدث إصدار
3. ثبّته على الجهاز (اسمح بالتثبيت من مصادر غير معروفة)
4. الدخول الافتراضي: **admin** / **admin123** — غيّر كلمة المرور بعد أول دخول

## 🔧 البناء

البناء تلقائي عبر GitHub Actions عند كل دفعة — ينتج APK موقّعاً في Releases.
للبناء اليدوي: `gradle -p android-app assembleRelease`

## 🗂️ هيكل المستودع

```
├── web-app/            تطبيق الويب (EduPro المعدّل)
│   ├── index.html
│   ├── js/  css/  print/  vendor/  assets/
│   └── print/reliable-print.js          ← محرك الطباعة المعزول (نفس المحطة)
│   └── print/print-settings-pro.js      ← محرك إعدادات الطباعة (نفس المحطة)
├── android-app/        غلاف الأندرويد (WebView + Bridge + Splash + قفل بصمة + طباعة حرارية)
└── .github/workflows/  البناء التلقائي
```
